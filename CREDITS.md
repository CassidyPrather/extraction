The texture rows are produced by `scripts/fetch_assets.py`. The exact source
files (URL, sha256) and the processing recipe for each output are recorded in
`scripts/assets_manifest.json`, and `docs/ASSETS.md` describes the pipeline.
`python3 scripts/fetch_assets.py --credits` lists every source the manifest
uses. Run it after adding one, so a missing row is easy to spot.

The sound effects themselves need no credit line — `src/synth.rs` generates
them from arithmetic at startup, so there are no audio assets to track.

The audio rows are produced by `scripts/fetch_audio.py --credits`: one row
per recording per sound set, listing only recordings that ended up in a
shipped file. The exact source files (URL, sha256), the cut points and the
mastering settings are recorded in `scripts/audio_manifest.json`, the file to
source mapping in `assets/audio/sounds.json`, and `docs/AUDIO.md` describes
the pipeline. Freesound uploaders are credited by their Freesound username.
