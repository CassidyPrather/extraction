# Before and after the 28 October playtest fixes: one contact sheet.
#
#   scripts/before_after.py docs/playtests/2026-10-28/shots.txt
#
# Builds `before` and `after` once each (scripts/build_at.sh), shoots every
# line below with both, and writes target/before_after/<before>_<after>/
# sheet.jpg and index.html. Try one line on its own with
# `--only NAME`; `--check` reads the list without shooting.
#
# Owners: when your fix lands, make your line show it. Add a line, or fix
# the staging of one below. One shot a line:
#
#   name | owner | what to look for | game arguments [| before's arguments]
#
# - Game arguments are the game's own flags. The rig adds --screenshot,
#   --size, --new-game, a fresh --data-dir, --frames 30 and --seed 7
#   (unless you give your own --frames or --seed).
# - Leading NAME=value words go into the game's environment
#   (EXTRACTION_YARD_AT=5 starts the yard at station 5).
# - --camera x,y,z,yaw,pitch: y 0 stands you there. Yaw 0 looks along -Z
#   and 90 along +X.
# - --gallery stages things in front of the camera (src/dev.rs:
#   `<gun>`, `<gun>+open`, `fp:<item>`, `treat`, `walker`, ...).
# - The fifth field is only for a shot whose staging is new with the fix:
#   the before build gets those arguments instead.
# - Pick a still moment that shows the fix. Use --hour day --weather
#   clearing unless the fix is about the light, and --no-robots unless
#   it's about them.
